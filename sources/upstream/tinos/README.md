# Tinos upstream snapshot

Источник: официальный репозиторий Google Fonts:
https://github.com/google/fonts/tree/main/ofl/tinos

В проект включён `Tinos-Regular.ttf` как открытый метрический каркас для
инженерного прототипа Tishte Serif. Название **Tinos** является зарезервированным
именем и не используется в производной гарнитуре.

Файл распространяется по SIL Open Font License 1.1. Исходные метаданные и
описание сохранены рядом с файлом, полное лицензионное уведомление приведено в
`licenses/TINOS-OFL-1.1.txt`.

Окончательная версия Tishte не должна оставаться простым переименованием Tinos:
контуры последовательно заменяются собственными, а исходный файл используется
для сохранения метрического каркаса и проверки производственного процесса.
