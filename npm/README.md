# Tishte Fonts

Tishte is a free type system made in the Mari El Republic. The package contains
Tishte Serif and Tishte Sans in WOFF2 and TTF, with Russian, Meadow Mari, Hill
Mari, extended Latin, figures, punctuation, and document symbols.

```bash
npm install @yasg1988/tishte-fonts
```

Import both families:

```js
import "@yasg1988/tishte-fonts";
```

Or import only one family:

```js
import "@yasg1988/tishte-fonts/serif.css";
import "@yasg1988/tishte-fonts/sans.css";
```

```css
body { font-family: "Tishte Sans", sans-serif; }
article { font-family: "Tishte Serif", serif; }
```

The font software is licensed under the SIL Open Font License 1.1. Tishte Serif
is derived from Tinos; Tishte Sans is derived from Arimo. Full provenance and
notices are included in the package and the
[project repository](https://github.com/yasg1988/tishte-fonts).
