# Tishte Sans

Tishte Sans is the screen-oriented companion to Tishte Serif. It supports
Russian, Meadow Mari, Hill Mari, and Latin in interfaces, dashboards, websites,
and presentations.

The static family contains Regular, Medium, SemiBold, and Bold, each with an
Italic counterpart. It is built reproducibly from pinned Arimo variable-font
binaries and normalized with FontTools.

Tishte Sans is based on the OFL-licensed Arimo project. The derivative origin
and modification notice are retained as required by the SIL Open Font License.
