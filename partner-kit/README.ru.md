# Пакет Tishte для офисных продуктов

Этот комплект предназначен для технической и редакционной оценки Tishte перед
включением в стандартный каталог шрифтов офисного продукта.

## Что предлагается

- **Tishte Serif** — документная антиква, метрически совместимая с Times New
  Roman: Regular, Bold, Italic и Bold Italic.
- **Tishte Sans** — экранный гротеск для интерфейсов, презентаций и таблиц:
  десять прямых и курсивных начертаний от Regular до ExtraBold.
- Поддержка русского, лугового марийского, горномарийского и расширенной
  латиницы; по 425 кодовых точек в каждом файле.
- Свободная лицензия SIL Open Font License 1.1.
- Зарегистрированный Microsoft идентификатор производителя `MRIE`.

Просьба рассматривается как включение в стандартный каталог доступных
гарнитур, а не как назначение Tishte шрифтом по умолчанию.

## Состав комплекта

- `fonts/ttf/` — 14 настольных TTF из официальных релизных архивов v1.100;
- `fonts/web/` — 14 WOFF2 и две таблицы CSS для веб-редакторов;
- `legal/` — OFL, сведения об авторах и происхождении;
- `specimens/` — карточки обеих гарнитур;
- `reports/` — выбранные машиночитаемые отчёты проверок;
- `samples/` — документы для быстрой проверки в офисных приложениях;
- `SHA256SUMS.txt` — контрольные суммы всех файлов комплекта.

## Быстрая проверка

1. Установите TTF из `fonts/ttf/` или подключите их штатным механизмом продукта.
2. Перезапустите приложение, если оно уже было открыто.
3. Откройте файлы из `samples/` и убедитесь, что в них нет замены гарнитуры.
4. Проверьте строки `Ӓӓ Ӧӧ Ӱӱ Ҥҥ Ӹӹ` и сочетание русского и латиницы.
5. Для серверного или веб-редактора подключите WOFF2 и CSS из `fonts/web/`.
