# Tishte Serif: пробелы и формирование текста v0.080

v0.080 расширяет проверенный документный контракт Tishte Serif с 214 до 216
знаков и устраняет дефект прежнего HarfBuzz-теста. Это инженерная версия для
пилота, а не официальный публичный релиз.

## Изменения

- в обязательный набор явно добавлены `U+0020 SPACE` и `U+00A0 NO-BREAK SPACE`;
- формат `data/document-charset.txt` теперь поддерживает записи `U+XXXX`;
- сборщик умеет собирать новую бинарную версию из проверенных SFD предыдущей
  контурной итерации;
- HarfBuzz-корпус разделяет латинские и кириллические script-run;
- выполнен полный поиск необходимых кернинговых поправок среди 216 × 216 пар
  для каждого из четырёх начертаний.

Корректирующие GPOS lookup не добавлялись: измеренная разница для всех пар
равна нулю. Контуры и исходный GPOS v0.070 сохранены без искусственной подгонки.

## Машинная проверка

| Начертание | Знаки | Пропуски | Ширины | Вертикальные метрики | FontForge | GPOS-дельты |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Regular | 216/216 | 0 | 0 | 0 | 0 | 0 |
| Bold | 216/216 | 0 | 0 | 0 | 0 | 0 |
| Italic | 216/216 | 0 | 0 | 0 | 0 | 0 |
| Bold Italic | 216/216 | 0 | 0 | 0 | 0 | 0 |

HarfBuzz проверяет 28 стилевых случаев: русский, луговомарийский,
горномарийский, латиницу, числа/символы и отдельные латинские/кириллические
кернинговые строки. При отключённых и включённых документных функциях разница
продвижения с Times New Roman равна нулю, `.notdef` отсутствует.

## Microsoft Office

- Word: 5/5 пар совпали по страницам, строкам и переносам; в языковой образец
  добавлены `A B`, `A B` и сумма с неразрывными пробелами; четыре начертания
  внедрены в каждый Tishte DOCX.
- Excel: два XLSX по два листа, формульных ошибок нет, PDF содержит контроль
  обычного и неразрывного пробела.
- PowerPoint: два PPTX по четыре слайда, расхождений высоты текста и
  переполнений нет, контроль пробелов отображается корректно.

## Ограничения статуса

v0.080 подтверждает инженерную совместимость, но не заменяет типографическую,
лингвистическую и юридическую экспертизу. До официального релиза остаются
полная оригинализация заявленного набора, проверка обоих марийских литературных
языков специалистами и пилот на обезличенных документах органов власти.
