# Текстовая фактура Tishte Serif v0.040

## Цель

Сформировать узнаваемый, но нейтральный ритм обычного служебного абзаца. Для
первой серии выбраны наиболее частотные строчные `а е н о р с у` и связанные с
ними латинские `a e n o p c u`.

## Принципы

- увеличенные внутренние просветы `о/o` и `р/p`;
- более открытая апертура `е/e` и `с/c`;
- спокойное плечо `n`;
- собственная слегка восходящая перекладина кириллической `н`;
- терминальные срезы продолжают систему v0.030;
- ширина каждого знака остаётся совместимой с Times New Roman.

Кириллические `а`, `е`, `о`, `р`, `с` используют общие контурные основы с
латиницей. Кириллические `н` и `у` сохраняют самостоятельные конструкции.

## Критерий приёмки

Изменения должны быть видны в увеличенном контрольном наборе, но не создавать
пёструю фактуру в служебном тексте 10–14 pt. Переносы и число строк не должны
меняться относительно метрического эталона.
