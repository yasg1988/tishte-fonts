# Tishte Serif: инженерное семейство v0.060

Версия v0.060 завершает технический контур первой документной семьи Tishte
Serif. В ней связаны четыре обязательных начертания:

1. Regular;
2. Bold;
3. Italic;
4. Bold Italic.

Это инженерный прототип, а не публичный релиз. Regular продолжает собственную
визуальную итерацию v0.040. Остальные три начертания пока используют открытый
OFL-каркас Tinos и предназначены для проверки метрик, семейных связей,
встраивания и поведения Microsoft Office. До релиза их рисунок должен быть
переработан в полноценную систему Tishte.

## Метрический результат

Каждое начертание проверено против соответствующего файла Times New Roman:

| Tishte Serif | Эталон | Знаки | Пропуски | Ширины | Вертикальные метрики |
| --- | --- | ---: | ---: | ---: | ---: |
| Regular | Times New Roman Regular | 214/214 | 0 | 0 расхождений | 0 расхождений |
| Bold | Times New Roman Bold | 214/214 | 0 | 0 расхождений | 0 расхождений |
| Italic | Times New Roman Italic | 214/214 | 0 | 0 расхождений | 0 расхождений |
| Bold Italic | Times New Roman Bold Italic | 214/214 | 0 | 0 расхождений | 0 расхождений |

Набор включает русский, луговомарийский, горномарийский, базовую латиницу,
цифры, валюты и документные специальные символы. Для `※` ширина Tinos
синхронизирована с эталоном при сборке; контуры Times New Roman не копируются.

FontForge возвращает одинаковую маску валидации `36` (`0x04` — пересечения
контуров, `0x20` — отсутствующие экстремумы) для всех четырёх файлов. Это
наследованное состояние инженерного каркаса, принятое только для прототипа.
Перед публичным релизом ошибки должны быть разобраны по глифам и устранены в
оригинальных контурах Tishte.

## Семейные метаданные

- семейство: `Tishte Serif Prototype`;
- стили: `Regular`, `Bold`, `Italic`, `Bold Italic`;
- вес: 400 для Regular/Italic и 700 для Bold/Bold Italic;
- корректные `fsSelection` и `head.macStyle` для выбора начертаний Office;
- `OS/2.fsType = 0`: разрешено установочное встраивание;
- лицензия: SIL Open Font License 1.1;
- зарезервированные имена Tinos и Liberation удалены из пользовательских
  названий производного семейства.

## Microsoft Word

Повторно собраны пять пар документов Times/Tishte: распоряжение, письмо,
протокол, таблица и языковой образец. Всего проверено 10 DOCX и 12 страниц.

- число страниц совпало во всех пяти парах;
- число строк совпало во всех пяти парах;
- прежнее расхождение жирного заголовка устранено настоящим Bold;
- DOCX с Tishte содержит внедрённые Regular, Bold, Italic и Bold Italic;
- визуально не обнаружены обрезка, наложения, пустые страницы, отсутствующие
  знаки или повреждённые таблицы.

## Microsoft Excel

Созданы два XLSX с одинаковым содержанием: Times New Roman и Tishte Serif.
Каждый содержит лист реестра и лист четырёх начертаний.

- оба файла пересчитаны штатным Excel 16.0;
- формульных ошибок нет;
- оба варианта экспортированы на две страницы PDF;
- даты, суммы, проценты и марийские знаки отображаются без пропусков;
- визуальная структура и печатная пагинация совпадают.

## Microsoft PowerPoint

Созданы две презентации по четыре слайда. Проверены крупные заголовки, отдельные
луговомарийский и горномарийский блоки, четыре начертания и плотная таблица.

- число слайдов и фигур совпадает;
- высоты текстовых блоков совпадают;
- переполнения текстовых рамок не обнаружены;
- шрифты внедрены в PPTX через параметр `EmbedFonts` метода `SaveAs`;
- оба варианта экспортированы штатным PowerPoint 16.0 в PDF и визуально
  проверены.
