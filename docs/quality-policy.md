# Политика качества Tishte Serif

Воспроизводимый автоматический шлюз качества применяется к четырём
начертаниям TTF и WOFF2. Обязательны: 423/423 знака, ноль расхождений с числовым
контрактом Times New Roman, эквивалентное формирование NFC/NFD, нулевая маска
FontForge, успешная санитарная проверка OTS и отсутствие ошибок уровня FAIL в
применимом профиле FontBakery.

`data/times-new-roman-metrics.json` содержит только числовые ширины, вертикальные
метрики и разреженный набор парных корректировок. Контуры, инструкции и иные
данные проприетарного шрифта в репозиторий не копируются. Для каждого из четырёх
эталонных файлов сохранены версия, уникальный идентификатор, размер и SHA-256.
Файл позволяет одинаково собирать и проверять Tishte без наличия Times New Roman.

## Исключения FontBakery

- `family/vertical_metrics`, `family/win_ascent_and_descent` и
  `os2_metrics_match_hhea`: значения намеренно равны соответствующим значениям
  Times New Roman, чтобы не менять строки и страницы существующих документов.
- `tabular_kerning`: исходное поведение пары цифр Times New Roman сохраняется
  для совпадения формирования текста; документный режим отдельно проверяется с
  отключённым дискреционным кернингом.

Производственные файлы ограничены объявленными 423 кодовыми точками и
замыканием OpenType. Проверки `base_has_width` и `case_mapping` выполняются как
обычные обязательные проверки.

Предупреждения FontBakery сохраняются в отчёте и не скрываются. Текущие
предупреждения о вертикальных метриках, ширинах математических знаков и мягком
дефисе обусловлены контрактом совместимости с Times New Roman. Предупреждение
о контуре дефиса проверено визуально; предупреждение о `typoAscender` связано с
унаследованными метрическими значениями. Ошибки уровней FAIL, ERROR и FATAL не
допускаются.

Проверка `freetype_rasterizer` запускается отдельно для каждого файла по
относительному пути. Это обходит ложный `cannot open resource` во FreeType-py на
Windows для абсолютного пути с кириллицей, не исключая проверку ни для одного
TTF.
