# Межплатформенная и офисная проверка v0.130

v0.130 проверен в двух независимых контурах:

- Ubuntu 24.04 в GitHub Actions: FontForge, HarfBuzz/FontTools, OTS,
  FontBakery, TTF и WOFF2;
- Windows с установленными настольными Microsoft Word, Excel и PowerPoint.

## Word

Созданы пять пар документов Times New Roman / Tishte: приказ, письмо,
протокол, таблица и языковой образец. Результат: одинаковое число страниц и
строк во всех парах, различий раскладки нет.

| Документ | Страницы | Строки | Результат |
|---|---:|---:|---|
| Приказ | 1 | 34 | совпадает |
| Письмо | 1 | 28 | совпадает |
| Протокол | 2 | 71 | совпадает |
| Таблица | 1 | 131 | совпадает |
| Языки | 1 | 28 | совпадает |

## Excel

Обе книги содержат по два листа, ошибок формул нет, экспорт в PDF успешен.

## PowerPoint

Обе презентации содержат по четыре слайда. Сравнены 31 текстовая область:
расхождений высоты и переполнения нет.

Файлы испытаний создаются локально в `artifacts/` и не входят в историю Git из-за
размера. Итоговые JSON-отчёты включаются в пакет кандидата на выпуск.
