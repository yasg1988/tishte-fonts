# Сторонние компоненты

Tishte Serif создан как модифицированная версия Tinos. Исходный проект:
https://github.com/googlefonts/tinos

Copyright 2026 The Tinos Project Authors.

Tinos и Tishte Serif распространяются по SIL Open Font License 1.1. Полный
текст лицензии находится в `LICENSE.txt`. Исходные бинарники Tinos не входят в
репозиторий Tishte; автоматическая проверка оригинальности при необходимости
получает закреплённую upstream-версию отдельно и сверяет её SHA-256.

Tishte Sans создан как модифицированная версия Arimo. Исходный проект:
https://github.com/googlefonts/arimo

Copyright 2020 The Arimo Project Authors.

Arimo и Tishte Sans распространяются по SIL Open Font License 1.1. Исходные
бинарники Arimo не входят в репозиторий Tishte: сборка получает два файла из
закреплённого коммита официального репозитория Google Fonts и проверяет их
размер и SHA-256 по `data/arimo-upstream.json`.
